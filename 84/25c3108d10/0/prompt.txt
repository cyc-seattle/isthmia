**Design decisions worth flagging:**

1. **The `sync_run` task isn't queue-driven.** Discovery failing needs to surface in the same invocation, not get silently retried by the queue's own backoff — conflating "discovery is broken" with "one offering needs a retry" was the trap the design doc warns about, one level up. So `enqueueDueOfferings` calls `queue.enqueue` once (for grouping/UI purposes, via `parent_id`) but drives discovery directly and marks that row `done`/`failed` itself; only `sync_offering` tasks go through `runQueue`.
2. **Failure signal simplified to "not done."** A single-attempt failure leaves a task `pending` (queue-scheduled retry), not `failed` (exhausted). Since `enqueueDueOfferings` resets every offering to `attempts: 0` on every invocation (by the queue's own `planEnqueue` contract), a persistently-failing offering essentially never reaches `attempts &gt;= max_attempts` — it just gets one fresh attempt every scheduled run, matching the old model's "retry forever, once per run" behavior. So `runSync` treats any child task that isn't `"done"` after the drain as this run's failure, rather than only `"failed"`.
3. **`--dry-run` bypasses the queue entirely** (full discovery, direct per-offering loop, same as `--camp`). The queue's own `readItems`/`createItems` dry-run no-op means a dry run's enqueue never persists, so nothing would ever become claimable — going through `runQueue` in dry-run mode would silently do nothing. This is called out in the README.
4. **Skip vs. synced is no longer distinguishable from the task's final status** (`"done"` covers both an offering that wasn't due and one that synced). I treated this as an acceptable loss of granularity given the queue is now the audit trail; flagging it in case that's not the intended trade-off.

**Left alone:** each offering task now re-reads the full shared tables independently (`readSharedTables`), rather than the old single batched read shared across all camps in one run — a natural consequence of per-offering isolation, but a real increase in Directus round-trips for a club with many camps.
